# 公開資料、權利與隱私邊界

本次只發布自行撰寫的研究程式、方法／設定、彙整統計與研究圖表。公開來源SHA供稽核，不代表提供下載或再散布授權。

| 類型 | 公開內容 | 不公開內容 |
|---|---|---|
| 市場資料 | 資料欄位、調整方式、期間與檔案SHA | 原始或調整OHLCV、供應商完整回應 |
| 模型結果 | seed／模型／狀態彙整、配對檢定、圖表 | checkpoint、權重、pickle、完整工作站ZIP |
| 新聞 | 來源／年份／市場事件的彙整涵蓋、情緒與時間品質統計 | 全文、摘要、標題、文章清單、逐篇FinBERT／Gemini回應、私人檔案 |
| 環境 | 套件名稱／版本、計算設定 | 虛擬環境、快取、伺服器路徑、PID日誌、帳戶或憑證 |

市場來源是原研究的Yahoo／yfinance回溯快照。使用者須自行確認供應商使用條款及研究資料權利；本repo沒有替其原資料重新授權。重新下載會產生不同修訂版本，不得直接標示為原快照的重現。

Apple Newsroom重建資料是現在重新取得的歷史網頁；發布日期不證明當年內容版本或first-seen。企業官方來源也不代表全市場新聞。原FNSPID的檔案授權、釋出版本及第三方正文權利需各自確認，本repo不轉載其全文或大檔。未取得新聞應標示UNKNOWN，不能補成沒有新聞。

外部方法專案：[stockllm-pit-news](https://github.com/yoyocar2333/stockllm-pit-news)。不vendor其程式／語料；外部依賴各依原授權使用。此PR不擅自為既有研究與第三方內容新增全面授權；原E0檔案維持原有狀態。

`.gitignore`排除data、outputs、logs、vendor、環境、模型與archive。它只是第一道防線；發布檢查另外檢查追蹤檔案、大小、秘密格式、私有路徑及逐篇新聞欄位。新的資料或報告仍須重新人工審查。
